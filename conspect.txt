1) ссылка на другую страницу в шаблоне.

    пример ссылки в django на другую страницу при помощи обращения по имени функции обработчика:

        <li><a href="{% url 'articles' %}">Статьи</a></li>

    вот пример функции обработчика:

        def articles(request):
            return render(request, "articles.html")

    также для работы нужно указать name внутри функции path() внутри переменной urlpatterns



2) в urls.py можно сослаться на другие приложения внутри urlpatterns:

    path("articles/", include("hexlet_django_blog.article.urls")),

        (все пути, которые начинаются с "articles/", 
        будут перенаправляться в 
        hexlet_django_blog.article.urls)


3) для подключения приложения к основному пакету:
    1. задайте имя в apps.py
    2. добавьте имя приложения в список INSTALLED_APPS в файле настроек
    3. убедитесь, что приложение внутри главного пакета

4)  при подключении приложений через include внутри 
    файла urls проекта нужно прописывать им name в их urls файлах 

5)  шаблоны настраиваются в settings файле в разделе TEMPLATES

    DIRS — параметр, который перечисляет директории, 
    где будет производиться поиск шаблонов

    APP_DIRS — параметр, который разрешает Django 
    искать шаблоны в директориях приложений.
    Включена по умолчанию.

    Когда APP_DIRS включен, в каждом подключенном 
    приложении будут по умолчанию искаться директории 
    templates, а в них — шаблоны.

6)  По умолчанию в качестве директории с 
    шаблонами принято указывать templates:

    "DIRS": [BASE_DIR / "templates"],

7)  {% extends "название_шаблона" %} - конструкция для
    наследования шаблона.
